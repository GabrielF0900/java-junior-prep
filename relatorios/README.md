# Central de Estudos e Desafios

[Voltar ao README principal](../README.md)

Esta central reúne desafios resolvidos, exercícios em andamento, documentação individual, links para os códigos, testes e evidências, explicações Feynman e análise de complexidade. Navegue pela trilha e depois pela semana e pelo desafio.

## Separação de responsabilidades

| Local | Responsabilidade |
| --- | --- |
| [src/](../src/) | Código-fonte oficial e testes automatizados; preservar a implementação do estudante |
| relatorios/ | Índices, documentação individual, resultados e explicações |
| relatorios/&lt;trilha&gt;/semanaN/&lt;desafio&gt;/README.md | Registro individual de cada novo desafio |
| Subpasta imagens/ do desafio | Evidências reais; o README da pasta orienta sua inclusão |
| [HISTORICO_ESTUDOS.md](../HISTORICO_ESTUDOS.md) | Continuidade das sessões e ponto de retomada |
| [materiais/](../materiais/) | Materiais teóricos de consulta |
| [docs/](../docs/) | Arquitetura e registros de reorganização |
| [index.html](../index.html) e [AGENTS.md](../AGENTS.md) | Calendário e regras pedagógicas |

Os relatórios Java Core já existentes em HTML/PDF permanecem em seus locais. A criação de uma página ou pasta de imagens não comprova execução de teste nem existência de print.

## Legenda de status

| Status | Significado |
| --- | --- |
| Não iniciado | Somente planejamento, enunciado ou reserva; sem implementação do exercício |
| Em andamento | Implementação ou aprendizagem ainda em desenvolvimento |
| Em validação | Implementação existente; testes, evidências, explicação ou revisão ainda pendentes |
| Concluído | Implementação, testes, explicação Feynman e revisão concluídos, com aprendizagem demonstrada |

A existência de arquivo não significa conclusão. O status de Two Sum é apresentado como concluído **segundo o histórico de estudos**, que registra a informação de Gabriel; os campos antigos ainda pendentes no relatório foram preservados. Contains Duplicate continua **Em validação**.
